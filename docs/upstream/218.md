# Upstream #218: keyboard characterization

[Issue #218](https://github.com/nulloy/nulloy/issues/218) asks for selected-track
Return/Enter playback and convenient MacBook deletion. The sole live comment
[1904696449](https://github.com/nulloy/nulloy/issues/218#issuecomment-1904696449)
says activation should already work and references configurable actions
(`06985f1`). Issue-number and “return key”/“keyboard playlist” PR searches found
no matching work. Existing `itemActivated -> playItem`, NAction shortcut parsing,
and window-level QAction routing are retained, not replaced.

## Runtime result

**11 QtTest results passed, 0 failed, 0 skipped** in 2.091 seconds with Linux
Qt 6.8.2 XCB under Xvfb. The offscreen CTest entry also passed in 2.09 seconds.
Evidence: `/home/hermes/workspace/nulloy-swarm/evidence/218/xcb-final.txt` and
`ctest-final.txt`.

The independent harness compiles actual NPlaylistWidget/item, NAction,
Qxt's platform-independent implementation, settings, GStreamer engine, TagLib,
and track formatter. Only plugin discovery supplies the real engine directly;
existing `_TESTS_` synchronized fakesinks replace physical audio/video devices.
Qxt's native registration/filter methods are explicit **fatal-if-called** link
seams: no global hook or simulated successful registration is claimed.
The fixture duplicates the small production action-to-widget connections and
NPlayer's window-level addAction scope, not the entire action manager/player.

Checks:

- Return and keypad Enter activate the selected, not currently loaded row,
  both while playing and stopped, with exactly one mediaChanged signal.
- Return/Enter with a text editor focused do not activate the playlist.
- Default Delete removes the selected entry through actual NAction/QAction
  shortcut delivery; Delete in QLineEdit only edits text.
- Rebinding removal to Backspace works, and Backspace in QLineEdit only edits
  text. **The existing default SpeedReset Backspace binding is first cleared**
  to avoid an ambiguous user configuration.
- Default Backspace continues to trigger SpeedReset without removing entries.

These characterize working behavior on base `027d81a`; no production fix or
TDD regression-red claim is made. An initial fixture expected the literal string
“Delete”, but Qt serializes it as “Del”; the final test checks the equivalent
QKeySequence, not platform-specific spelling. Offscreen layout warnings do not
occur in the XCB verification. Existing Qxt/Qt/TagLib compiler warnings remain.
